# Audio Interface

## Important Note
This is being made on KiCAD 10. If you are using a different version and wish to make contributions there may be problems.

## Getting Started
To get this project on your computer, ensure you have git installed on your computer and in your terminal run:\
```
git clone https://github.com/fernd4wg/audio_interface
```

After that, open up the *audio_interface.kicad_pro* file through KiCAD.\

Done.

## 3D Models
I am going to use 3rd party 3D models for this project because KiCAD does not have all the necessary 3D models for this PCB.\

I will provide a fork of my KiCAD 3D model directory that you can replace with yours if you so wish.\

Additionally, I will provide a folder with the 3rd party 3D models I use for this project in this repository. ***Note** that those being here will not make them appear on the 3D model of the PCB. You will need to set that up yourself if you do not replace your KiCAD 3D model library with mine*\
